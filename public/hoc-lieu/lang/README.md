# Ảnh hoạt động Làng Maker

Mỗi ảnh một tệp `.webp`, tên là mã trong kế hoạch. Thiếu tệp thì khung trên trang tự ẩn.

| Mã | Ảnh |
|---|---|
| A1 | Con đường 8 chặng (infographic) |
| A2 | Trẻ chơi NEO One / ThingBot buổi đầu ở Làng |
| A3 | Làng nghề truyền thống |
| A4 | Xưởng Làng Maker hiện đại |
| F1 | Buồng nuôi tằm BlueSilk do các con làm |
| G1 | Team Vietnam FGC 2025 Panama (cả đội) |
| G2 | Team Vietnam FGC thi đấu / sửa robot |
| G3 | Team Vietnam × Hope School |

Chuyển ảnh: `cwebp -q 82 anh.jpg -o A2.webp`. Ảnh có mặt trẻ em chỉ dùng khi phụ huynh đã đồng ý.
